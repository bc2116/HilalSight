# repo-map

1. Read `AGENTS.md`, `README.md`, and `docs/agent/` first.

3. Use only commands evidenced in `docs/agent/build-and-test.md` or current manifests; record unknowns as TODOs.
4. Summarize the Python/FastAPI, React/Vite, and `sites/` surfaces plus their relevant docs.
5. Preserve dirty work and report adapter-path conflicts before proposing edits.
