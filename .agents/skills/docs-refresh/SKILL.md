# docs-refresh

1. Read the affected `README.md`, `docs/agent/` files, and relevant manifests first.
2. Verify any command against `docs/agent/build-and-test.md` or a current manifest before documenting it.
3. Make minimal operator-focused edits and preserve existing scientific and safety guidance.
4. Do not document secrets, customer data, private paths, or unverified workflow assumptions.
5. Record uncertain commands or runbooks as TODOs instead of guessing.
